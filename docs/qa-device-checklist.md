# בדיקות על מכשירים — לפני שחרור

רשימה לבדיקה ידנית על טלפונים אמיתיים, לכל מה שלא נבדק בסביבת הפיתוח (הבדיקות האוטומטיות לא מריצות מכשיר).
סמנו ✓ / ✗ והוסיפו הערה קצרה. מכשירים מומלצים: סמסונג (Android 13+), שיאומי, Android ישן (10–11), אייפון (iOS 16+).

## לפני הכל (קונסולה, פעם אחת)

- [ ] `firebase deploy --only firestore:rules`
- [ ] `FUNCTIONS_DISCOVERY_TIMEOUT=60 firebase deploy --only functions` (כולל `sendReminders`, `refreshAdminStats`, `refreshAdminStatsNow`)
- [ ] Firebase Analytics: שמירת נתוני אירועים ל־2 חודשים, Google Signals כבוי, מסנן נתונים `internal_user = true`
- [ ] Play — Data Safety, App Store — תווית פרטיות: נוספו "אינטראקציה עם המוצר" (Analytics)
- [ ] iOS: מפתח APNs מועלה ל־FCM (בלעדיו אין התראות push באייפון, והתזכורות נשארות מקומיות)

## אנשי קשר

- [ ] כניסה ראשונה ל"הוספת אנשי קשר": מופיע הסבר לפני חלון ההרשאה של המערכת, והחלון נפתח רק אחרי "לאפשר גישה"
- [ ] סירוב פעם אחת → מסך "סירבת"; סירוב קבוע → מסך עם כפתור להגדרות המכשיר
- [ ] מההגדרות חזרה לאפליקציה אחרי מתן הרשאה → הרשימה נטענת מעצמה
- [ ] ספר טלפונים עם 1,000+ אנשי קשר: הטעינה מסתיימת, בלי קפיאה, עם פס התקדמות
- [ ] מספרים בכתיבות שונות: `+972 54…`, `972 54…`, `00972…`, `054-…`, מספר שהועתק מוואטסאפ — כולם מופיעים
- [ ] אותו אדם בשני חשבונות (Google + SIM) → שורה אחת
- [ ] מספר קווי → "מוסתרים N אנשי קשר (מספר קווי או עסק) · הצגה", ובחיפוש מופיע עם התגית "מספר קווי"
- [ ] הוספת איש קשר בטלפון בזמן שהאפליקציה ברקע → חזרה לאפליקציה מציגה אותו
- [ ] חבר שמנהל כרטיס אישי: התגית "כרטיס אישי בשדכן" ברשימה, ובהוספה מוצעת "בקשת גישה לכרטיס" במקום מילוי ידני
- [ ] כפתור הרענון ליד המיון עובד
