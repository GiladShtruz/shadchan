  - [ ] **ביטול ידני:** כשהחיבור לא הושלם — הגדרות ← מאגר זוגי ← "ביטול החיבור וחזרה למאגר שלי" (או אותו כפתור במסך הטעינה) → שניהם חוזרים למאגר האישי, שום נתון לא חסר
  - [ ] **התנתקות והתחברות מחדש באמצע:** רחל מתנתקת בזמן שהחיבור בתהליך ומתחברת שוב → אותו מצב בדיוק (ממשיך / הושלם / בוטל) — אף פעם לא מאגר ריק ולא מאגר חדש
  - [ ] **רק צד אחד אישר:** משה יצר הזמנה ורחל לא הזינה → אצל משה הכול רגיל, אין שום מצב ביניים
  - [ ] **שני המכשירים פתוחים בזמן החיבור:** אצל משה (שלא לחץ כלום) מופיע "טוענים את המאגר הזוגי" ואז המאגר המשותף, בלי לסגור ולפתוח
  - [ ] **אחרי החיבור:** שניהם נכנסים, רואים אותו מאגר, הוספה/עריכה אצל אחד מופיעה אצל השני תוך שניות
- [ ] **פירוק:** הגדרות ← מאגר זוגי ← ניהול מתקדם ← פיצול → תצוגה מקדימה של מה כל אחד מקבל ואישור מפורש → כל אחד חוזר למאגר אישי עם החברים שהוסיף; רעיון שמחבר בין שני הצדדים נשאר אצל שניהם עם כל ההיסטוריה; שום דבר לא נמחק
